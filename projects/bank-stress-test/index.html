Bank stress test model

A scenario-driven capital stress test for a bank, built from scratch in Excel as a way to learn how regulators think about resilience.

Type
Risk modeling
Tools
Excel
Scenarios
Baseline, Adverse, Severe
Status
Learning project

The idea

A bank is asked a simple question: if the economy turns, do you still have enough capital? This model builds that question as a working spreadsheet. It is a learning project, built to understand the mechanics end to end rather than to reproduce any real institution.

How it works

  • Scenarios. Three macro paths (Baseline, Adverse, Severe) feed the same model. A set of option buttons switches the whole workbook between them, so the outputs can be compared without rebuilding anything.
  • Risk weights. Risk-weighted assets are computed with an Internal Ratings-Based (IRB) approach, where each exposure's risk weight comes from its own probability of default, loss given default and maturity rather than a fixed regulatory bucket.
  • Capital. Losses and income under each scenario flow through to capital, which is measured against requirements.

What I took from it

The main lesson was how much the answer depends on the assumptions behind the scenarios, and how a clean switchable structure makes those assumptions visible. Building the IRB step by hand made the regulatory formula feel like something with a reason behind it instead of a black box.

Scope: this is a teaching model with simplified inputs. It illustrates the method, and should not be read as a forecast for any real bank.
